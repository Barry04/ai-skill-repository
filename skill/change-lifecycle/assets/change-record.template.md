# 需求记录

将下列内容填为本次已知事实，删除不适用项。未知保留 `unknown`，不要把模板占位内容当作真实证据。

```yaml
id: change-id
goal: 本次需求目标
scope:
  - 相关接口、字段、行为或文件
development_start:
  revision: unknown
  existing_work: unknown
stage: designing
production_exposure:
  status: unknown
  evidence: []
external_consumers:
  status: unknown
  evidence: []
data_retention:
  status: unknown
  evidence: []
deployments: []
compatibility_decisions: []
open_questions: []
updated_at: unknown
```

## 关键进展

只追加影响方案、状态或兼容决定的简短事实；已确认的原始需求/方案可引用现有文档，不重复复制。状态和证据写法见 [记录约定](../references/record-and-evidence.md)。
